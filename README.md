# Grafiker Yayınları

grafiker-yayinlari.blogspot.com sitesinin varlıkları.

- `assets/` site stili ve betiği
- `data/books.json` katalog verisi (487 kitap, 19 dizi)
- `img/k/` kapaklar (orijinal 146×226), `img/b/` büyük kapak görselleri (orijinal)
- `img/logo/` vektörel logo (dikey, yatay, amblem; siyah, beyaz)
- `pdf/` içindekiler ve önsöz dosyaları
- `belgeler/` uluslararası yayınevi belgesi ve yayın indeksleri
- `blogger/theme.xml` Blogger teması
